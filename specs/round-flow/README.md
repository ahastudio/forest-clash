# 라운드 진행

## Background

대전 격투 게임은 타이틀에서 시작해 여러 라운드를 치르고 결과를 보여 준 뒤 다시 타이틀로 돌아온다.
각 단계가 언제 시작하고 끝나는지, 승패를 어떻게 가르는지가 한 판의 틀이다.

## Goal

타이틀 → 라운드 시작 안내 → 대전 → K.O. 또는 시간 초과 → 다음 라운드 또는 결과 → 타이틀로 한 판을 이어 가고, 두 판을 먼저 이긴 쪽을 가린다.

## How it works

### 단계

- 타이틀: 20프레임이 지난 뒤 공격 버튼을 새로 누르면 시작한다. 1P면 컴퓨터와, 2P만이면 둘이서 대전이다.
- 라운드 시작 안내: 110프레임. ROUND n이 나오다가 마지막 45프레임에 FIGHT!가 나온다. 입력은 비워서 받는다.
- 대전: 한 라운드 60초(3600프레임)다. 0이 되면 시간 초과다.
- K.O. 또는 시간 초과 안내: K.O.는 180프레임, 시간 초과는 160프레임이다. 이긴 쪽을 알린다.
- 결과: 두 판을 먼저 이긴 쪽의 승리를 보인다. 120프레임이 지난 뒤 공격 버튼을 누르면 타이틀로 돌아간다.

### 승패

- K.O.는 이긴 쪽이 한 판을 얻는다.
- 시간 초과는 체력이 많은 쪽이 한 판을 얻고, 같으면 아무도 얻지 못한다.
- 두 판을 먼저 얻으면 판이 끝난다. 그렇지 않으면 다음 라운드가 시작된다.

### 화면

- 가운데 시계에 라운드 번호와 남은 초가 보이고, 10초 안쪽이면 붉게 바뀐다.
- 결과 화면에는 색종이가 떨어진다.
- Space로 일시정지하면 조작 안내가 보인다.
