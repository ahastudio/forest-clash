# Feature Specification: 기술

## Overview

기술은 데이터 표(`move-specs.ts`)로 정의하고, 파생값(끝 프레임, 전체 길이, 경직)은 표에서 계산한다.
공격하는 쪽의 상태가 `attack`인 동안 매 프레임 판정 구간에 들었는지 보고, 닿으면 막는지 맞는지를 가른다.
잡기는 발동 프레임에 범위와 상대 상태를 보고 바로 처리한다.

## User Scenarios & Testing (mandatory)

### User Story 1: 버튼으로 일반기를 낸다

- As: 플레이어는
- I: 서서·앉아서·앞 입력과 버튼으로 일반기를 낼 수 있다
- So: 거리와 높이에 맞는 기술을 고르기 위해

#### Acceptance Scenarios

Scenario 1: **발동**

- Given: 상대가 사거리 안에 있을 때
- When: 서서 약펀치를 누르면
- Then: 3프레임째에 맞는다

Scenario 2: **앉아 약킥**

- Given: 상대가 사거리 안에 있을 때
- When: 아래+약킥을 누르면
- Then: 하단 기술이 나가고 4프레임째에 맞는다

Scenario 3: **앞+강펀치**

- Given: 앞을 누른 채
- When: 강펀치를 누르면
- Then: 내려찍기 주먹(상단)이 나가고 앞으로 나아간다

### User Story 2: 연계와 취소

- As: 플레이어는
- I: 약한 기술을 이어 누르고 맞힌 뒤 특수기로 끊어 이을 수 있다
- So: 콤보를 만들기 위해

#### Acceptance Scenarios

Scenario 1: **링크**

- Given: 앉아 약펀치를 맞혔을 때
- When: 앉아 약킥을 이어 누르면
- Then: 앉아 약펀치와 앉아 약킥이 연달아 맞는다

Scenario 2: **취소**

- Given: 앉아 약킥을 맞혔을 때
- When: →↓ + 약펀치를 누르면
- Then: 후딜을 끊고 대공 어퍼가 나가 서로 다른 기술 3개가 이어진다

### User Story 3: 특수기

- As: 플레이어는
- I: 돌진 팔꿈치, 대공 어퍼, 강타를 낼 수 있다
- So: 접근, 대공, 막혀 있는 상대 공략에 쓰기 위해

#### Acceptance Scenarios

Scenario 1: **대공 어퍼 무적**

- Given: 대공 어퍼의 앞 5프레임에
- When: 상대가 약펀치를 맞히려 하면
- Then: 지나가고 맞지 않는다

Scenario 2: **돌진 팔꿈치**

- Given: ↓→ + 약펀치를 눌렀을 때
- When: 12프레임이 지나면
- Then: 앞으로 나아가며 판정이 나오고 맞히면 쓰러뜨린다

### User Story 4: 잡기

- As: 플레이어는
- I: 가까이서 앞이나 뒤로 밀면서 강펀치나 강킥을 눌러 상대를 잡아 던질 수 있다
- So: 막고 있는 상대를 공략하기 위해

#### Acceptance Scenarios

Scenario 1: **잡힘**

- Given: 상대가 가까이 있을 때
- When: 앞이나 뒤로 밀면서 강펀치나 강킥을 누르면
- Then: 크게 휘두르지 않고 잡기가 나가, 방어 여부와 상관없이 잡혀 피해 12를 입는다

Scenario 2: **들어 올림**

- Given: 상대를 잡았을 때
- When: 던지기가 끝나기까지
- Then: 머리 위(높이 50 이상)까지 들었다가 앞으로 던진다

Scenario 3: **잡히면 끝**

- Given: 잡혔을 때
- When: 어떤 버튼이나 방향을 눌러도
- Then: 풀리지 않고 들어 올려졌다가 던져진다

Scenario 4: **잡는 사이의 약한 공격**

- Given: 잡기를 누른 직후(발동 전)에
- When: 상대가 약펀치로 때리면
- Then: 잡기가 끊기고 잡으려던 쪽이 맞는다

Scenario 5: **발동 전의 강공격**

- Given: 상대가 강킥을 막 시작해 아직 판정이 나오지 않았을 때
- When: 잡기가 발동하면
- Then: 상대가 잡힌다

Scenario 6: **범위 밖**

- Given: 상대가 멀리 있을 때
- When: 앞이나 뒤로 밀면서 강펀치를 누르면
- Then: 잡기가 나가지 않고 앞+강펀치가 나간다

## Functional Requirements (mandatory)

- FR-1: MUST 기술은 발동 → 판정 → 후딜 순서로 진행하며 판정 프레임에만 맞힌다.
- FR-2: MUST 경직은 이득 + 판정 + 후딜이다.
- FR-3: MUST 서서 약펀치(중단): 발동/판정/후딜 3/3/3, 막힘 +1, 맞음 +5, 피해 3, 취소 가능.
- FR-4: MUST 서서 약킥(중단): 발동/판정/후딜 5/3/8, 막힘 -1, 맞음 +2, 피해 4, 취소 가능.
- FR-5: MUST 서서 강펀치(중단): 발동/판정/후딜 8/3/15, 막힘 -2, 맞음 +1, 피해 7, 취소 가능.
- FR-6: MUST 서서 강킥(중단): 발동/판정/후딜 10/3/14, 막힘 -5, 맞음 -2, 피해 9, 취소 가능.
- FR-7: MUST 앉아 약펀치(중단): 발동/판정/후딜 3/3/4, 막힘 0, 맞음 +4, 피해 3, 취소 가능.
- FR-8: MUST 앉아 약킥(하단): 발동/판정/후딜 4/3/6, 막힘 -1, 맞음 +3, 피해 4, 취소 가능.
- FR-9: MUST 앉아 강펀치(대공)(중단): 발동/판정/후딜 5/3/18, 막힘 -8, 맞음 -4, 피해 8, 취소 가능, 맞히면 띄운다.
- FR-10: MUST 앉아 강킥(쓸기)(하단): 발동/판정/후딜 10/3/18, 막힘 -6, 맞음 쓰러짐, 피해 8, 취소 불가.
- FR-11: MUST 내려찍기 주먹(상단): 발동/판정/후딜 20/3/18, 막힘 -6, 맞음 +4, 피해 8, 앞으로 나아간다.
- FR-12: MUST 돌진 발차기(중단): 발동/판정/후딜 11/4/16, 막힘 -5, 맞음 0, 피해 7, 앞으로 나아간다.
- FR-13: MUST 공중 약펀치(상단): 발동 4, 판정 8프레임, 막힘 경직 12, 맞음 경직 15, 피해 4.
- FR-14: MUST 공중 약킥(상단): 발동 5, 판정 8프레임, 막힘 경직 12, 맞음 경직 15, 피해 4.
- FR-15: MUST 공중 강펀치(상단): 발동 6, 판정 5프레임, 막힘 경직 14, 맞음 경직 18, 피해 7.
- FR-16: MUST 공중 강킥(상단): 발동 8, 판정 6프레임, 막힘 경직 14, 맞음 경직 18, 피해 8.
- FR-17: MUST 돌진 팔꿈치(↓→ + 약/강펀치): 발동/판정/후딜 12/4/20, 막힘 -8, 맞음 쓰러짐, 피해 8 / 강은 발동/판정/후딜 16/5/24, 막힘 -10, 맞음 쓰러짐, 피해 10, 앞으로 나아가고 맞히면 쓰러뜨린다.
- FR-18: MUST 대공 어퍼(→↓ + 약/강펀치): 발동/판정/후딜 4/6/26, 막힘 -30, 맞음 쓰러짐, 피해 9 / 강은 발동/판정/후딜 6/8/32, 막힘 -34, 맞음 쓰러짐, 피해 12, 약은 앞 5프레임, 강은 앞 7프레임 무적이며 맞히면 띄운다.
- FR-19: MUST 강타(중단): 발동/판정/후딜 14/4/22, 막힘 -8, 맞음 쓰러짐, 피해 7, 쓰러뜨린다.
- FR-20: MUST 잡기: 발동 9(강펀치 8, 강킥 10과 비슷하고 약한 기술 3\~5보다 느리다), 헛치면 후딜 24, 피해 12, 쓰러뜨린다. 방어를 무시한다. 범위는 중심 거리 90 안이다.
- FR-21: MUST 약한 일반기는 맞히거나 막힌 뒤 특수기로 취소할 수 있다(취소 가능으로 표시된 기술).
- FR-22: MUST 맞음 이득이 +인 약한 기술은 다음 약한 기술이 발동하기 전에 상대가 풀리지 않아 이어진다(링크).
- FR-23: MUST 잡힌 상대는 아무것도 할 수 없고 풀 수 없다. 잡을 수 있는 상태는 땅에서 무적이 아니고, 행동 가능하거나 막힘 경직이거나 공격이 아직 발동 전인 때뿐이다(판정이 나온 공격은 잡을 수 없다).
- FR-24: MUST 공격이 발동한 뒤의 공격 상자 둘레 3은 맞을 수 있는 상자에 더해진다.

## Constraints (mandatory)

- CON-1: MUST 기술의 프레임 수치는 이 문서와 테스트가 같은 값을 쓰고, 수치를 바꾸면 이 문서와 테스트를 함께 고친다.
- CON-2: MUST 기술 정의는 데이터 표(`move-specs.ts`가 합치는 `move-specs-ground.ts`, `move-specs-air.ts`, `move-specs-special.ts`)에만 둔다.
- CON-3: MUST 공중 기술은 모두 상단이다.
- CON-4: MUST 잡기는 방어를 무시하고, 잡을 수 있는 상태는 땅에서 무적이 아니고 행동 가능하거나 막힘 경직인 때뿐이다.
- CON-5: MUST 근접·원거리 기술 구분, 낙법, 맥스 모드는 이번 범위에서 뺀다.

## Success Criteria (mandatory)

- SC-1: 서서·앉아서 여덟 기술이 정확히 발동 프레임에 맞는다.
- SC-2: 아홉 기술의 막힘 이득과 맞음 이득을 재 보면 기술 표와 같다.
- SC-3: 앉아 약펀치 → 앉아 약킥 → 대공 어퍼 콤보가 이어지고 서로 다른 기술 3개가 맞는다.
- SC-4: 잡기는 방어를 무시하고, 한 번 잡히면 풀 수 없고, 발동 전의 약한 공격에 지며, 멀면 나가지 않는다.
- SC-5: 대공 어퍼의 앞 5프레임에는 상대 약펀치가 맞지 않는다.
