## Requirements

- 범위는 작게 한다.
- 모든 모션은 방향 두 개를 차례로 누르는 것이다(대각선이 필요하지 않다).
- 공중 킥의 판정은 발끝이고 다리는 오른쪽 아래 대각선이다.
- 잡기는 근거리에서 앞이나 뒤로 밀면서 강펀치·강킥을 누르면 큰 공격 대신 나가고 방어를 무시한다. 한 번 잡히면 아무것도 못 하며 풀 수 없다. 발동은 강공격과 비슷하게 걸리고, 그 사이 약한 공격에 맞는다.

## Technical Decisions

| Decision | Rationale |
| -------- | --------- |
| 경직 = 이득 + 판정 + 후딜 | 테스트에서 측정한 실제 이득이 표와 같도록 맞춘 식이다. |
| 뻗은 팔다리를 맞을 수 있는 상자에 더한다 | 헛치면 위험하게 하기 위해서다(공격 상자 둘레 3). |
| 약한 기술의 막힘 이득을 +1 이하로 둔다 | guard 기능의 결정을 따른다(연타하는 쪽이 이기는 것을 막기 위해서다). |
| 잡기는 앞이나 뒤로 밀면서 강펀치나 강킥을 눌러 낸다 | 근거리에서 앞+강공격이 큰 공격(발동 20, 11)으로 나가는 대신 방어를 무시하고 잡기 위해서다. |
| 잡기 발동은 9프레임이다 | 약한 기술(3~5)에는 지고 강펀치(8), 강킥(10)과 비슷하게 맞춘 값이다. 연타 뒤 너무 쉽게 잡혀서 6에서 9로 늦췄다. |
| 발동 전의 공격은 잡을 수 있다 | 잡는 사이 약한 공격은 먼저 판정이 나와 이기고, 막 시작한 강공격은 발동 전이라 잡히는 타이밍 싸움을 만들기 위해서다. 판정이 나온 공격은 잡을 수 없다. |
| 잡기 범위는 90이다 | 연타가 막혀 상대가 밀려난 거리에서도 닿게 하려고 70에서 늘렸다. 앞+강공격은 이 범위 밖에서만 나간다. |
| 잡기 풀기를 없앴다 | 잡히면 거기서 끝이다. 컴퓨터 상대의 풀기 전술과 난이도 값도 지웠다. |

## Issues Encountered

### 1. 잡기 입력에서 방향을 한 프레임만 누르면 잡기가 나가지 않는다

**문제**:

앞으로 밀면서 강펀치를 누르는 입력을 시나리오 테스트에서 한 프레임만 주었더니 잡기가 아니라 일반 강공격이 나갔다.

**원인**:

방금 누른 버튼은 한 프레임 뒤부터 유효하다. 그 사이에 방향을 놓으면 버튼이 읽히는 시점에는 방향이 없어 일반기로 처리된다.

**해결**:

실제 조작처럼 방향을 계속 누른 채 버튼을 누르도록 테스트의 입력을 고쳤다. 입력 규칙은 바꾸지 않았다.

**결과**:

앞과 뒤, 강펀치와 강킥의 네 입력이 모두 잡기로 나간다.

## Learnings

### 표와 실제를 테스트로 맞춘다 (2026-10-19)

프레임 표의 이득을 문서로만 두지 않고 실제로 기술을 맞히고 막은 뒤 움직일 수 있게 되는 시각을 재서 표와 비교한다.
