### Phase 3: Implementation ✅

**작업 내역**:

1. Go 서버를 만들었다(구글 토큰 검증, 대기열 매칭, 입력 전달, 승패 기록, JSON 파일 저장).
2. 입력 부호화, 락스텝, 서버 메시지 읽기, 웹소켓 연결, 온라인 흐름, 구글 로그인, 환경 값 읽기를 만들었다.
3. 타이틀 메뉴를 만들고 게임이 메뉴의 선택으로 판을 시작하게 했다. 온라인 대전 중에는 락스텝으로 프레임을 진행하고 일시정지를 막았다.
4. 보안 정책에 구글 로그인과 웹소켓을 열고, 서버 통신은 한 파일에서만 허용하게 점검 도구를 고쳤다.
5. 품질 점수 기준에 맞게 긴 함수를 나눴다.
6. 타이틀 선택지를 정사각형에 가까운 버튼 세 개와 줄바꿈 글자로 바꿨다.
7. 타이틀 뒤에서 캐릭터가 싸우는 배경 대전(연습용 엔진)을 만들었다.
8. 구글 로그인을 stub으로 먼저 구현했다(클라이언트의 `stub-login.ts`, 서버의 `stub.go`와 `AUTH_STUB`).
9. 버튼 위의 커서를 손가락 모양으로 맞췄다. 게임이 만드는 클릭 대상(타이틀의 캔버스 버튼, 공격 버튼 네 개, 일시정지 버튼, 로그인 창의 취소 버튼)을 전부 찾아 고쳤고, 조이스틱은 버튼이 아니라 끌어서 쓰는 영역이라 그대로 두었다.
10. 개발용 서버를 이 서버만 켜고 끄는 전용 스크립트(`server/dev-server.sh`)로 좁혔다. 실제 경로(`pwd -P`)로 비교해 켜기, 상태, 끄고 다시 켜기를 확인했다. 게임 개발 서버는 그대로 유지되었다.
11. 게임 주소와 서버 주소가 다른 컴퓨터 주소일 때 연결되도록, 서버 주소의 출처를 보안 정책의 연결 허용에 자동으로 더하고(`vite.config.ts`) 서버의 웹소켓 출처를 개인 설정 파일(`server/.dev-server.env`)로 바꿀 수 있게 했다. 켠 서버에 허용된 출처로는 웹소켓 연결이 성립하고(101) 다른 출처는 거절되는(403) 것을 확인했다.
