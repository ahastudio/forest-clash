# 조작과 입력

## Background

대전 격투 게임은 방향과 버튼을 프레임 단위로 읽어 기술을 고른다.
키보드로는 대각선을 누르기 어렵고, 한 키보드를 두 사람이 나눠 써야 한다.
그래서 버튼은 네 개로 줄이고 모든 모션을 방향 두 개를 차례로 누르는 것으로 만든다.

## Goal

버튼 네 개와 방향 입력만으로 걷기, 점프, 방어, 일반기, 특수기, 잡기를 낼 수 있게 한다.
두 사람이 한 키보드로 둘이서 대전할 수 있게 한다.

## How it works

### 키 배치

- 1P(오른쪽 캐릭터)는 방향키와 I(약펀치) K(약킥) O(강펀치) L(강킥)을 쓴다.
- 2P(왼쪽 캐릭터)는 W A S D와 R(약펀치) F(약킥) T(강펀치) G(강킥)을 쓴다.
- 위 줄이 펀치, 아래 줄이 킥이고, 왼쪽 열이 약하고 오른쪽 열이 강하다.

### 입력 읽기

- 엔진이 매 프레임 두 캐릭터의 입력을 받는다.
- 방향은 숫자패드 번호(1~9)로 바꿔 최근 40칸까지 기록한다. 앞뒤는 캐릭터가 바라보는 쪽 기준이다.
- 버튼은 새로 눌렀는지와 눌린 지 몇 프레임인지(최대 99)를 기록한다.
- 타격 정지 중에도 입력을 받지만 버튼의 나이는 늘지 않는다.

### 모션과 동시 입력

- ↓→ + 약펀치/강펀치는 돌진 팔꿈치, →↓ + 약펀치/강펀치는 대공 어퍼다.
- ↓→↓→ + 강펀치는 분노 필살기다(분노 게이지가 가득일 때).
- 방향 두 개를 차례로 누르면 되고, 대각선을 섞어 눌러도 같은 모션으로 본다.
- 약펀치+약킥은 구르기, 강펀치+강킥은 강타다.
- 가까이서(중심 거리 90 안) 앞이나 뒤로 밀면서 강펀치나 강킥을 누르면 큰 공격 대신 잡기가 나간다. 방향 없이 누르면 일반 강공격이 나간다.

### 진행과 보조 키

- 타이틀과 결과 화면에서는 어떤 공격 버튼이든 새로 누르면 진행한다. 1P의 버튼이면 컴퓨터와, 2P의 버튼만이면 둘이서 대전한다.
- Space는 일시정지와 계속, M은 소리 켜고 끄기, H는 판정 상자 표시다. 모바일에서는 화면의 일시정지 버튼이 Space를 대신한다([모바일 조작](../mobile-controls/README.md)).
- 창을 벗어나거나 탭이 가려지면 눌린 키를 모두 놓고, 대전 중이면 일시정지한다.
