# Feature Specification: 조작과 입력

## Overview

버튼 네 개(약펀치, 약킥, 강펀치, 강킥)와 방향 입력으로 모든 동작을 낸다.
엔진이 프레임마다 입력을 읽어 모션과 동시 입력을 판정한다.
두 사람이 한 키보드를 나눠 쓰며, 컴퓨터 상대도 같은 모양의 입력을 낸다.

## User Scenarios & Testing (mandatory)

### User Story 1: 한 키보드로 둘이서 조작한다

- As: 플레이어는
- I: 1P는 방향키와 I K O L로, 2P는 W A S D와 R F T G로 캐릭터를 조작할 수 있다
- So: 한 키보드로 둘이서 대전하기 위해

#### Acceptance Scenarios

Scenario 1: **1P 키**

- Given: 아무 키도 누르지 않았을 때
- When: ←와 I를 누르면
- Then: 1P 입력은 왼쪽 방향과 약펀치이고 2P 입력은 비어 있다

Scenario 2: **2P 키**

- Given: 아무 키도 누르지 않았을 때
- When: R을 누르면
- Then: 2P 입력은 약펀치이다

Scenario 3: **키가 겹치지 않음**

- Given: 두 플레이어의 키 배치가 정해져 있을 때
- When: 두 배치를 비교하면
- Then: 16개 키가 하나도 겹치지 않는다

Scenario 4: **키를 놓음**

- Given: W와 G를 누르고 있을 때
- When: W를 놓으면
- Then: 2P의 위 입력은 사라지고 강킥은 남는다

### User Story 2: 방향 두 개를 차례로 눌러 특수기를 낸다

- As: 플레이어는
- I: 대각선을 누르지 않고 방향 두 개를 차례로 눌러 특수기를 낼 수 있다
- So: 키보드로도 모션을 쉽게 내기 위해

#### Acceptance Scenarios

Scenario 1: **돌진 팔꿈치**

- Given: 서 있는 캐릭터가 있을 때
- When: ↓, →를 차례로 누르고 약펀치를 누르면
- Then: 돌진 팔꿈치(약)가 나간다

Scenario 2: **대공 어퍼**

- Given: 서 있는 캐릭터가 있을 때
- When: →, ↓를 차례로 누르고 약펀치를 누르면
- Then: 대공 어퍼(약)가 나간다

Scenario 3: **겹친 모션**

- Given: →, ↓, →를 차례로 눌렀을 때
- When: 약펀치를 누르면
- Then: 마지막 입력이 앞이므로 돌진 팔꿈치가 나가고 대공 어퍼는 나가지 않는다

Scenario 4: **대각선 호환**

- Given: ↓, ↘, →를 차례로 눌렀을 때
- When: 약펀치를 누르면
- Then: 돌진 팔꿈치가 나간다

Scenario 5: **시간 초과**

- Given: ↓, →를 누른 뒤 10프레임이 지났을 때
- When: 약펀치를 누르면
- Then: 모션으로 인정하지 않는다

### User Story 3: 타이틀은 메뉴로, 결과 화면은 버튼 하나로 넘긴다

- As: 플레이어는
- I: 타이틀에서는 메뉴의 대전 방식을 눌러 시작하고, 결과 화면에서는 공격 버튼 하나로 돌아올 수 있다
- So: 별도의 시작 키를 찾지 않기 위해

#### Acceptance Scenarios

Scenario 1: **컴퓨터와 대전**

- Given: 타이틀이 20프레임 이상 나와 있을 때
- When: 「혼자서 컴퓨터와」 버튼을 마우스나 터치로 누르면(게임이 1P의 공격 버튼을 새로 누른 입력으로 바꿔 엔진에 준다)
- Then: 컴퓨터와 대전이 시작된다

Scenario 2: **둘이서 대전**

- Given: 타이틀이 20프레임 이상 나와 있을 때
- When: 「같은 컴퓨터에서 둘이서」 버튼을 누르면(게임이 2P의 공격 버튼만 새로 누른 입력으로 바꿔 엔진에 준다)
- Then: 둘이서 대전이 시작된다

Scenario 3: **키보드로는 시작하지 않는다**

- Given: 타이틀이 20프레임 이상 나와 있을 때
- When: 키보드의 방향이나 공격 버튼을 누르면
- Then: 시작하지 않는다. 키보드의 공격 버튼은 결과 화면에서 새로 누를 때만 진행한다

### User Story 4: 보조 키와 창 이탈

- As: 플레이어는
- I: Space, M, H로 일시정지, 소리, 판정 상자 표시를 바꿀 수 있다
- So: 게임을 멈추고 소리와 판정을 확인하기 위해

#### Acceptance Scenarios

Scenario 1: **일시정지**

- Given: 게임이 진행 중일 때
- When: Space를 누르면
- Then: 일시정지하고 브라우저가 화면을 스크롤하지 않는다

Scenario 2: **소리와 판정 상자**

- Given: 소리가 켜져 있고 판정 상자가 꺼져 있을 때
- When: M과 H를 누르면
- Then: 소리가 꺼지고 판정 상자가 보인다

Scenario 3: **창 이탈**

- Given: 대전 중일 때
- When: 창이 포커스를 잃으면
- Then: 눌린 키를 모두 놓고 일시정지한다

## Functional Requirements (mandatory)

- FR-1: MUST 버튼은 네 개(A 약펀치, B 약킥, C 강펀치, D 강킥)와 방향 넷으로 입력한다.
- FR-2: MUST 1P는 방향키와 I K O L, 2P는 W A S D와 R F T G를 쓴다.
- FR-3: MUST 방향은 매 프레임 숫자패드 번호(1~9)로 최근 40칸까지 기록하고, 앞뒤는 캐릭터가 바라보는 쪽 기준이다.
- FR-4: MUST 버튼은 새로 눌렀는지와 눌린 뒤 몇 프레임인지(최대 99)를 기록한다.
- FR-5: MUST 타격 정지 중에도 입력을 받아 두되 버튼의 나이는 늘리지 않고, 같은 방향을 중복해서 기록하지 않는다.
- FR-6: MUST 버튼은 누른 다음 프레임부터 6프레임 안(특수기는 8프레임 안)이면 유효하다(미리 눌러도 된다).
- FR-7: MUST 앞이나 뒤를 15프레임 안에 두 번 새로 누르면 달리기와 뒤 대시 입력이다.
- FR-8: MUST 모션은 ↓→(돌진 팔꿈치), →↓(대공 어퍼), ↓→↓→(분노 필살기)이며, 방향 두 개를 차례로 누르면 되고 대각선을 섞어도 같은 모션으로 본다.
- FR-9: MUST 모션은 마지막 입력이 9프레임(분노 필살기는 10프레임) 안이고, 처음부터 마지막까지 16프레임(분노 필살기는 34프레임) 안일 때만 인정한다.
- FR-10: MUST ↓→와 →↓가 함께 완성되면 더 최근에 끝난 모션을 쓴다.
- FR-11: MUST 약펀치+약킥은 구르기, 강펀치+강킥은 강타이며 2프레임 안에 함께 눌러야 한다.
- FR-12: MUST 가까이서(중심 거리 90 안) 앞이나 뒤로 밀면서 강펀치나 강킥을 누르면 큰 공격 대신 잡기가 나간다. 방향 없이 누르면 일반 강공격이, 약한 버튼이면 일반 약공격이 나가고, 앉아 있으면 앉아 강펀치나 쓸기가 나간다.
- FR-13: MUST 타이틀은 메뉴를 눌러 시작하고(게임이 누른 메뉴를 엔진이 받는 1P 또는 2P의 공격 버튼 입력으로 바꿔 준다), 결과 화면은 어떤 공격 버튼이든 새로 누르면 타이틀로 돌아간다.
- FR-14: SHOULD Space는 일시정지, M은 소리, H는 판정 상자 표시다.
- FR-15: MUST 창이 포커스를 잃으면 눌린 키를 모두 놓고 대전 중이면 일시정지하고, 탭이 가려져도 대전 중이면 일시정지한다.

## Constraints (mandatory)

- CON-1: MUST 진행, 다시 시작, 컴퓨터 전환 같은 별도 키를 두지 않는다. 보조 키는 Space, M, H뿐이다.
- CON-2: MUST 모든 모션은 대각선 없이 낼 수 있다.
- CON-3: MUST 키보드 입력과 컴퓨터 입력은 같은 모양(방향 넷과 버튼 넷)이다.
- CON-4: MUST 입력을 읽고 모션을 판정하는 코드는 엔진 안에 두고, 키보드를 읽는 코드와 분리한다.

## Success Criteria (mandatory)

- SC-1: 두 플레이어의 키 16개가 겹치지 않는다.
- SC-2: 방향 두 개를 차례로 누른 입력이 테스트에서 돌진 팔꿈치와 대공 어퍼로 나간다.
- SC-3: 모션이 오래되었거나 느리게 이어지면 모션으로 인정하지 않는다.
- SC-4: 타이틀의 메뉴에서 컴퓨터는 컴퓨터와, 둘이서는 둘이서 대전을 시작한다.
- SC-5: 창을 벗어나면 눌린 키가 모두 풀리고 대전 중이면 일시정지한다.
