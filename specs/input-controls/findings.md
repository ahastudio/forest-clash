## Requirements

- 버튼은 KOF 98처럼 네 개이고, 위 줄은 약펀치(왼쪽)와 강펀치(오른쪽), 아래 줄은 약킥(왼쪽)과 강킥(오른쪽)이다.
- 진행에 쓰는 별도 키는 두지 않는다. 어떤 공격 버튼이든 누르면 진행한다.
- 문제: 키보드로는 대각선을 누르기 어렵다.

## Technical Decisions

| Decision | Rationale |
| -------- | --------- |
| 모든 모션은 방향 두 개를 차례로 누르는 것 | 키보드로는 대각선을 누르기 어려워서다. 대각선이 낀 입력도 같은 모션으로 받는다. |
| 버튼 입력은 6프레임(특수기는 8프레임) 미리 눌러도 받는다 | 약한 기술의 연계(링크)와 취소를 쉽게 내기 위해서다. |
| 방금 누른 버튼은 한 프레임 뒤부터 유효하다 | 두 버튼을 동시에 누른 입력(구르기, 강타)과 한 버튼 입력을 구분하기 위해서다. |
| 별도 진행 키를 두지 않는다 | 타이틀과 결과 화면은 공격 버튼으로 진행한다. |
| 잡기 입력은 앞이나 뒤로 밀면서 강펀치나 강킥이다 | KOF 방식이다. 근거리에서 앞+강공격이 큰 공격 대신 잡기가 된다. 거리 범위는 90이다. |

## Issues Encountered

### 1. 대각선이 필요한 모션은 키보드로 내기 어렵다

**문제**:

모션에 대각선 입력이 필요하면 키보드로 내기 어렵다.

**원인**:

대각선은 방향키 두 개를 동시에 눌러야 한다.

**해결**:

모션 표를 방향 두 개를 차례로 누르는 순서(↓→, →↓, ↓→↓→)를 기본으로 두고, 대각선이 낀 순서도 같은 모션으로 받도록 했다.

**결과**:

대각선 없이 낸 입력과 대각선을 섞은 입력이 모두 테스트에서 같은 기술로 나간다.

### 2. 잡기 입력에서 방향을 한 프레임만 누르면 잡기가 나가지 않는다

**문제**:

앞으로 밀면서 강펀치를 누르는 입력을 시나리오 테스트에서 한 프레임만 주었더니 잡기가 아니라 일반 강공격이 나갔다.

**원인**:

방금 누른 버튼은 한 프레임 뒤부터 유효하다. 그 사이에 방향을 놓으면 버튼이 읽히는 시점에는 방향이 없어 일반기로 처리된다.

**해결**:

실제 조작처럼 방향을 계속 누른 채 버튼을 누르도록 테스트의 입력을 고쳤다. 입력 규칙은 바꾸지 않았다.

**결과**:

앞과 뒤, 강펀치와 강킥의 네 입력이 모두 잡기로 나간다.

## Learnings

### 키보드 모션은 순서만 보면 된다 (2026-10-19)

대각선 없이 방향 두 개를 차례로 누르는 것으로도 모든 모션을 낼 수 있고, 패드의 대각선 입력도 같은 표에 넣어 두 방식을 함께 받는다.
