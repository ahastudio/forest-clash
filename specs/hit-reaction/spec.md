# Feature Specification: 맞았을 때

## Overview

타격이 맞으면 피해, 경직, 보상(게이지, 콤보, 타격 정지)을 정하고, 맞은 쪽을 경직·띄움·쓰러짐 중 하나로 보낸다.
체력이 다하면 라운드가 끝난다.
여러 타격이 같은 프레임에 닿았으면 먼저 모두 모은 뒤 차례로 처리해 맞교환이 된다.

## User Scenarios & Testing (mandatory)

### User Story 1: 맞으면 굳는다

- As: 플레이어는
- I: 공격을 맞으면 정해진 시간 동안 굳고 그동안 콤보를 당한다
- So: 맞힌 쪽이 이어 공격할 수 있게 하기 위해

#### Acceptance Scenarios

Scenario 1: **맞음 이득**

- Given: 서서 약펀치를 맞혔을 때
- When: 두 캐릭터가 움직일 수 있게 되는 시각을 재면
- Then: 맞힌 쪽이 5프레임 먼저 움직인다

Scenario 2: **타격 정지**

- Given: 강킥을 맞혔을 때
- When: 정지 프레임을 보면
- Then: 양쪽이 11프레임 멈춘다

### User Story 2: 카운터 히트와 맞교환

- As: 플레이어는
- I: 상대가 기술을 쓰는 중에 맞히면 더 큰 보상을 받는다
- So: 빠른 기술로 상대 기술을 끊는 싸움을 하기 위해

#### Acceptance Scenarios

Scenario 1: **카운터 히트**

- Given: 상대가 약킥(발동 5)을 쓰는 중에
- When: 약펀치(발동 3)로 먼저 맞히면
- Then: 카운터 히트이고 피해가 25퍼센트 늘며 상대 기술이 끊긴다

Scenario 2: **맞교환**

- Given: 두 캐릭터가 같은 프레임에
- When: 약펀치를 서로 맞히면
- Then: 둘 다 맞는다

### User Story 3: 쓰러뜨리고 K.O.로 끝낸다

- As: 플레이어는
- I: 쓸기로 상대를 쓰러뜨리고 체력이 다하면 K.O.로 날려 보낼 수 있다
- So: 반격과 압박의 수단으로 쓰고 라운드를 끝내기 위해

#### Acceptance Scenarios

Scenario 1: **쓰러짐**

- Given: 쓸기를 맞았을 때
- When: 땅에 닿으면
- Then: 36프레임 쓰러져 있다가 14프레임 동안 일어나고, 그 뒤에 행동할 수 있다

Scenario 2: **K.O.**

- Given: 체력이 1인 상대에게
- When: 약펀치를 맞히면
- Then: K.O.가 되고 맞은 쪽이 맞은 방향으로 높이 날아간다

## Functional Requirements (mandatory)

- FR-1: MUST 맞음 경직 동안 방어와 행동은 불가능하다.
- FR-2: MUST 맞음 경직은 이득 + 판정 + 후딜이고, 카운터 히트면 4프레임 늘어난다.
- FR-3: MUST 타격 정지는 약한 기술 8, 강한 기술 11, 분노 필살기 14, 잡기 8프레임이고, 카운터 히트면 3프레임 늘어난다. 정지 중에도 입력은 받는다.
- FR-4: MUST 상대가 기술을 쓰는 중(발동~판정 구간)에 맞히면 카운터 히트이며 피해가 25퍼센트 늘고(반올림), 상대의 기술이 끊긴다.
- FR-5: MUST 같은 프레임에 서로 맞히면 둘 다 맞는다.
- FR-6: MUST 땅에서 맞은 쪽은 기술의 밀림 × (1 − 0.85) × 1.2만큼 밀려나고, 땅에 있는 때린 쪽은 기술의 밀림 × (1 − 0.85) × 0.25만큼 반대로 밀린다. 밀림은 프레임마다 0.85배로 줄어 0.05 밑이면 멈춘다.
- FR-7: MUST 띄우는 기술은 맞은 쪽을 공중으로 띄우고, 띄워진 쪽은 저글이 되는 기술(돌진 팔꿈치, 대공 어퍼, 분노 필살기, 공중 기술)만 맞으며 저글 한도는 2다.
- FR-8: MUST 쓰러뜨리는 기술을 맞은 쪽은 날아가 땅에 닿으면 쓰러지고, 36프레임 누워 있고(맞지 않음) 14프레임 일어난다(맞을 수 있음).
- FR-9: MUST 콤보 피해는 이어 맞을 때마다 8퍼센트씩, 공중에서 이어 맞을 때마다 10퍼센트씩 줄며 각각 최소 50퍼센트다. 피해는 최소 1이다.
- FR-10: MUST 콤보는 마지막 명중 뒤 70프레임 안에 또 맞히면 이어지고, 막히면 0이 된다.
- FR-11: MUST 체력이 다하면 K.O.이며 맞은 쪽은 맞은 방향으로 날아가고(세로 11, 가로 6) 라운드가 끝나며 이긴 쪽이 한 판을 얻는다.
- FR-12: MUST 맞았을 때 사건(hit)은 피해, 세기, 카운터 여부, 불꽃 위치를 담는다.

## Constraints (mandatory)

- CON-1: MUST 맞음 반응은 화면과 소리를 모르는 엔진 안에 둔다.
- CON-2: MUST 한 프레임의 타격들은 먼저 모두 모은 뒤 차례로 처리한다(처리 도중 상태 변화가 다른 타격의 닿음 판정을 바꾸지 않는다).
- CON-3: MUST 낙법과 슈퍼 점프는 이번 범위에서 뺀다.

## Success Criteria (mandatory)

- SC-1: 서서 약펀치를 맞혔을 때 맞음 이득이 표의 +5와 같다.
- SC-2: 카운터 히트의 피해가 기본 피해의 1.25배(반올림)이고 상대 기술이 끊긴다.
- SC-3: 같은 프레임에 서로 맞히면 둘 다 체력이 준다.
- SC-4: 쓸기를 맞은 쪽이 쓰러졌다가 일어나 행동할 수 있다.
- SC-5: 체력이 다한 쪽이 K.O.가 되어 맞은 방향으로 날아가고 이긴 쪽 승수가 오른다.
