# 분노 게이지와 필살기

## Background

대전 격투 게임의 게이지는 싸움의 흐름을 모아 한 번의 큰 기술로 바꾸는 장치다.
이 게임은 맥스 모드 같은 별도 상태 없이, 게이지가 가득 차면 분노 필살기 한 번을 쓸 수 있는 작은 규칙으로 만든다.

## Goal

때리고, 맞고, 막을 때마다 분노 게이지가 차고, 가득 차면 ↓→↓→ + 강펀치로 분노 필살기를 쓰게 한다.
게이지는 화면에서 보이고 가득 차면 눈에 띄게 알린다.

## How it works

### 게이지가 차는 규칙

- 게이지는 0에서 100까지다. 라운드마다 비운다.
- 맞히면 피해만큼, 맞으면 피해의 1.6배, 막으면 막은 쪽이 1.5, 때린 쪽이 2 찬다. 잡기도 맞힌 쪽 1.0배, 맞은 쪽 1.6배다.
- 게이지가 가득 차도 별도의 상태 변화(맥스 모드)는 없다.

### 분노 필살기

- 게이지가 가득일 때 ↓→↓→ + 강펀치를 입력하면 나간다. 쓰면 게이지를 모두 비운다.
- 앞 7프레임은 무적이다. 스트레이트, 하이킥, 올려치기가 연달아 나가고 피해는 7, 7, 12다.
- 막혀도 칩 피해 2를 주지만 막은 쪽 체력은 1 밑으로 줄지 않는다. 마지막 타는 맞은 쪽을 띄운다.
- 맞은 쪽의 맞음 경직은 22프레임, 막은 쪽의 막힘 경직은 14프레임이다.

### 화면 표시

- 체력 막대 아래에 분노 막대가 있다. 가득 차면 노랑과 주황으로 깜빡인다.
- 게이지가 가득이면 캐릭터 뒤에 주황빛이 맥동한다.
