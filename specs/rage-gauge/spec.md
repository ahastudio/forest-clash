# Feature Specification: 분노 게이지와 필살기

## Overview

분노 게이지는 캐릭터마다 가진 값이고, 100을 넘지 않게 오른다.
게이지가 가득이고 모션 입력이 완성되면 분노 필살기가 나가고 게이지가 빈다.
분노 필살기는 판정 구간 세 개를 가진 하나의 기술이다.

## User Scenarios & Testing (mandatory)

### User Story 1: 게이지가 찬다

- As: 플레이어는
- I: 때리고 맞고 막을 때마다 분노 게이지가 차는 것을 볼 수 있다
- So: 필살기 시기를 가늠하기 위해

#### Acceptance Scenarios

Scenario 1: **맞힘**

- Given: 서서 약펀치(피해 3)를 맞혔을 때
- When: 게이지를 보면
- Then: 맞힌 쪽은 3, 맞은 쪽은 4.8 찼다

Scenario 2: **막음**

- Given: 약펀치를 막았을 때
- When: 게이지를 보면
- Then: 막은 쪽은 1.5, 때린 쪽은 2 찼다

Scenario 3: **상한**

- Given: 게이지가 99일 때
- When: 더 맞히면
- Then: 100에서 멈춘다

### User Story 2: 분노 필살기를 쓴다

- As: 플레이어는
- I: 게이지가 가득일 때 ↓→↓→ + 강펀치로 필살기를 쓸 수 있다
- So: 한 번에 큰 피해를 주기 위해

#### Acceptance Scenarios

Scenario 1: **발동**

- Given: 게이지가 가득이고 상대가 가까울 때
- When: ↓→↓→ + 강펀치를 입력하면
- Then: 분노 필살기가 나가고 게이지가 비워진다

Scenario 2: **여러 타**

- Given: 분노 필살기가 맞았을 때
- When: 끝까지 진행되면
- Then: 두 번 이상 맞고 마지막은 띄운다

Scenario 3: **게이지 부족**

- Given: 게이지가 50일 때
- When: 같은 입력을 하면
- Then: 필살기가 나가지 않는다

Scenario 4: **막힘**

- Given: 필살기가 막혔을 때
- When: 막은 쪽 체력을 보면
- Then: 칩 피해로 줄지만 1 밑으로는 내려가지 않는다

### User Story 3: 화면에서 알아본다

- As: 플레이어는
- I: 게이지가 가득 찬 것을 화면에서 한눈에 알 수 있다
- So: 필살기를 쓸 수 있는 순간을 놓치지 않기 위해

#### Acceptance Scenarios

Scenario 1: **분노 막대**

- Given: 게이지가 가득일 때
- When: 체력 막대 아래를 보면
- Then: 막대가 노랑과 주황으로 깜빡인다

Scenario 2: **주황빛**

- Given: 게이지가 가득일 때
- When: 캐릭터를 보면
- Then: 뒤에 주황빛이 맥동한다

## Functional Requirements (mandatory)

- FR-1: MUST 분노 게이지는 0에서 100까지이며 라운드마다 비운다.
- FR-2: MUST 맞히면 피해만큼, 맞으면 피해의 1.6배가 찬다. 잡기에서도 맞은 쪽 1.6배, 맞힌 쪽 1.0배다.
- FR-3: MUST 막으면 막은 쪽이 1.5, 때린 쪽이 2 찬다.
- FR-4: MUST 게이지는 100을 넘지 않는다.
- FR-5: MUST 게이지가 가득이고 강펀치를 8프레임 안에 누르고 ↓→↓→ 모션이 완성되면 분노 필살기가 나간다.
- FR-6: MUST 분노 필살기를 쓰면 게이지를 모두 비운다.
- FR-7: MUST 분노 필살기는 70프레임이고 앞 7프레임은 무적이며, 판정 구간이 세 개(8~11, 20~23, 34~40프레임)이고 피해는 7, 7, 12다.
- FR-8: MUST 분노 필살기가 막히면 칩 피해 2를 주고 막은 쪽 체력은 1 밑으로 줄지 않는다.
- FR-9: MUST 분노 필살기의 마지막 타는 맞은 쪽을 띄우고, 맞음 경직은 22프레임, 막힘 경직은 14프레임, 타격 정지는 14프레임이다.
- FR-10: MUST 체력 막대 아래에 분노 막대가 있고, 가득 차면 노랑과 주황으로 깜빡인다.
- FR-11: MUST 게이지가 가득이면 캐릭터 뒤에 주황빛이 맥동한다.

## Constraints (mandatory)

- CON-1: MUST 게이지가 가득 차도 맥스 모드 같은 별도 상태 변화는 두지 않는다.
- CON-2: MUST 분노 필살기는 취소로 낼 수 있지만, 분노 필살기에서 다른 기술로 취소하지 않는다.
- CON-3: MUST 게이지의 값은 규칙이 정하고, 화면은 그 값을 보여 주기만 한다.

## Success Criteria (mandatory)

- SC-1: 약펀치를 맞혔을 때 맞힌 쪽 게이지가 피해만큼, 맞은 쪽 게이지가 1.6배 오른다.
- SC-2: 게이지가 100을 넘지 않는다.
- SC-3: 게이지가 가득일 때만 분노 필살기가 나가고 쓰면 게이지가 비워진다.
- SC-4: 분노 필살기가 두 번 이상 맞고 막혀도 막은 쪽 체력이 1 밑으로 줄지 않는다.
- SC-5: 게이지가 가득이면 분노 막대와 캐릭터가 깜빡이거나 맥동한다.
