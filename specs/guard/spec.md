# Feature Specification: 방어

## Overview

방어는 공격이 맞는 순간 판정한다.
방어할 수 있는 상태인지, 뒤를 누르고 있는지, 공격 높이에 맞는 자세인지를 차례로 본 뒤, 막혔으면 막은 쪽을 막힘 경직에 넣고 밀어내며 게이지와 타격 정지를 정한다.

## User Scenarios & Testing (mandatory)

### User Story 1: 높이에 맞는 자세로 막는다

- As: 플레이어는
- I: 공격 높이에 맞는 자세로 방어할 수 있다
- So: 상단과 하단을 읽는 싸움을 하기 위해

#### Acceptance Scenarios

Scenario 1: **중단**

- Given: 상대가 서서 약펀치(중단)를 쓸 때
- When: 서서 뒤를 누르거나 앉아서 아래+뒤를 누르면
- Then: 두 자세 모두 막는다

Scenario 2: **상단**

- Given: 상대가 앞+강펀치(상단)를 쓸 때
- When: 서서 뒤를 누르면 막고 앉아서 아래+뒤를 누르면
- Then: 서서는 막고 앉아서는 맞는다

Scenario 3: **하단**

- Given: 상대가 앉아 약킥(하단)을 쓸 때
- When: 앉아서 아래+뒤를 누르면 막고 서서 뒤를 누르면
- Then: 앉아서는 막고 서서는 맞는다

Scenario 4: **방어하지 않음**

- Given: 상대가 서서 약펀치를 쓸 때
- When: 아무것도 누르지 않으면
- Then: 맞는다

### User Story 2: 막은 뒤에도 계속 막는다

- As: 플레이어는
- I: 막힘 경직 중에도 계속 방어할 수 있다
- So: 연타를 막아 내기 위해

#### Acceptance Scenarios

Scenario 1: **연타**

- Given: 상대가 12프레임마다 약펀치를 연타할 때
- When: 뒤를 계속 누르고 있으면
- Then: 모두 막고 피해가 없다

Scenario 2: **잡기**

- Given: 막고 있을 때
- When: 상대가 가까이서 잡기를 쓰면
- Then: 방어를 무시하고 잡힌다

### User Story 3: 막힌 쪽이 위험해진다

- As: 플레이어는
- I: 막힌 기술의 후딜에 반격하고, 막힌 뒤 이득이 있는 약한 기술로 압박할 수 있다
- So: 무리한 공격을 벌주기 위해

#### Acceptance Scenarios

Scenario 1: **막힘 이득**

- Given: 약한 기술이 막혔을 때
- When: 움직일 수 있게 되는 시각을 재면
- Then: 표의 막힘 이득(예: 서서 약펀치 +1)과 같다

Scenario 2: **후딜 반격**

- Given: 강킥이 막혀 후딜일 때
- When: 막은 쪽이 약펀치로 반격하면
- Then: 맞는다

Scenario 3: **연타 대 반격**

- Given: 연타하는 쪽과 막고 반격하는 쪽이 8판 싸울 때
- When: 체력을 보면
- Then: 막고 반격하는 쪽이 대부분 이긴다

### User Story 4: 막으면 게이지가 찬다

- As: 플레이어는
- I: 막아도 분노 게이지가 찬다
- So: 수비 중에도 필살기를 준비하기 위해

#### Acceptance Scenarios

Scenario 1: **게이지**

- Given: 약펀치를 막았을 때
- When: 게이지를 보면
- Then: 막은 쪽은 1.5, 때린 쪽은 2 찼다

## Functional Requirements (mandatory)

- FR-1: MUST 방어는 상대 반대 방향(뒤)을 누르는 것이고, 앉아서 방어는 아래+뒤다.
- FR-2: MUST 방어 방향은 두 캐릭터의 위치로 판단한다.
- FR-3: MUST 땅에서 무적이 아니고 서 있거나 걷거나 앉아 있거나 막는 중일 때만 막을 수 있다.
- FR-4: MUST 중단은 서서와 앉아서 모두, 상단은 서서만, 하단은 앉아서만 막는다.
- FR-5: MUST 잡기는 방어를 무시한다.
- FR-6: MUST 막으면 피해가 없다. 분노 필살기만 칩 피해 2를 주며 체력은 1 밑으로 줄지 않는다.
- FR-7: MUST 막힘 경직 중에도 계속 막을 수 있고, 맞음 경직 중에는 막을 수 없다.
- FR-8: MUST 막은 쪽은 기술의 밀림 × (1 − 0.85)만큼 밀려나고, 땅에 있는 때린 쪽은 그 절반만큼 반대로 밀린다.
- FR-9: MUST 막은 쪽의 분노 게이지는 1.5, 때린 쪽은 2 찬다.
- FR-10: MUST 막힌 기술이 취소 가능이면 때린 쪽에 취소 표시가 남고, 때린 쪽의 콤보 수는 0이 된다.
- FR-11: MUST 막았을 때 타격 정지는 max(5, 기술의 타격 정지 − 2)프레임이다.
- FR-12: MUST 막힘 경직은 이득 + 판정 + 후딜이고, 막혔을 때의 이득은 기술 표의 값과 같다.

## Constraints (mandatory)

- CON-1: MUST 공중 방어와 가드 캔슬은 이번 범위에서 뺀다.
- CON-2: MUST 약한 기술의 막힘 이득은 +1 이하다(+3이면 연타하는 쪽이 이겼다).
- CON-3: MUST 방어 판정은 화면과 소리를 모르는 엔진 안에 둔다.

## Success Criteria (mandatory)

- SC-1: 중단·상단·하단과 서서·앉아서의 여섯 조합이 규칙대로 막음 또는 맞음이다.
- SC-2: 서서 약펀치 연타를 계속 막아도 피해가 없다.
- SC-3: 땅의 일반기 아홉 기술의 막힘 이득을 재 보면 기술 표와 같다.
- SC-4: 연타하는 쪽이 막고 반격하는 쪽에 대부분 진다.
- SC-5: 막으면 막은 쪽 게이지가 1.5, 때린 쪽 게이지가 2 찬다.
