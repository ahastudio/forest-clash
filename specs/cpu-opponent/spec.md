# Feature Specification: 컴퓨터 상대

## Overview

컴퓨터 상대는 사람과 같은 입력(방향과 버튼 네 개)만 낸다.
매 프레임 상황을 관찰하고, 전술을 위에서부터 시도해 판단을 얻고, 그 판단을 입력으로 바꾼다.
난이도는 표로 정해지고, 라운드와 전적에 따라 단계가 정해진다.

## User Scenarios & Testing (mandatory)

### User Story 1: 처음에는 봐주면서 시작한다

- As: 플레이어는
- I: 처음에는 쉬운 컴퓨터와 싸우고 라운드가 갈수록 어려운 컴퓨터와 싸운다
- So: 처음 하는 사람이 바로 지지 않고 실력에 맞춰 올라가기 위해

#### Acceptance Scenarios

Scenario 1: **1라운드**

- Given: 1라운드일 때
- When: 난이도를 보면
- Then: 아주 쉬움이다

Scenario 2: **2라운드와 그 뒤**

- Given: 2라운드일 때와 3라운드 이후일 때
- When: 난이도를 보면
- Then: 조금 쉬움, 그 뒤로는 보통이다

Scenario 3: **지고 있을 때**

- Given: 컴퓨터가 더 많이 이기고 있을 때
- When: 난이도를 보면
- Then: 기본 단계보다 한 단계 낮다

### User Story 2: 사람처럼 막고 반격한다

- As: 플레이어는
- I: 컴퓨터가 내 공격을 보고 높이에 맞춰 막고 빈틈에 반격하는 것을 본다
- So: 무작정 연타만으로 이기지 못하게 하기 위해

#### Acceptance Scenarios

Scenario 1: **막기**

- Given: 상대가 기술을 쓰기 시작해 반응 지연이 지났을 때
- When: 놓치지 않으면
- Then: 높이에 맞춰 막는다(하단은 앉아서)

Scenario 2: **반격**

- Given: 상대 기술이 헛쳐 후딜일 때
- When: 확률에 걸리면
- Then: 약펀치로 반격한다

Scenario 3: **끊기**

- Given: 상대 기술의 발동이 느릴 때
- When: 확률에 걸리면
- Then: 약펀치로 끊는다

Scenario 4: **대공**

- Given: 상대가 위에서 떨어질 때
- When: 확률에 걸리면
- Then: 대공 어퍼 입력을 낸다

### User Story 3: 다가가서 공격한다

- As: 플레이어는
- I: 컴퓨터가 거리에 맞춰 다가오고 공격을 섞는 것을 본다
- So: 단조롭지 않은 상대와 싸우기 위해

#### Acceptance Scenarios

Scenario 1: **접근**

- Given: 상대가 아주 멀 때
- When: 판단하면
- Then: 앞으로 걷고 가끔 달려 붙는다

Scenario 2: **공격**

- Given: 사거리 안에 붙었을 때
- When: 판단하면
- Then: 난이도별 빈도로 약펀치, 약킥, 앉아 공격, 강한 공격, 뒤로 물러남을 섞는다

Scenario 3: **압박**

- Given: 아주 쉬움이 아닌 난이도에서 상대가 막고 있을 때
- When: 판단하면
- Then: 읽은 방어 자세에 맞춰 하단, 상단, 잡기를 섞는다

Scenario 4: **필살기**

- Given: 분노 게이지가 가득이고 가까울 때
- When: 판단하면
- Then: 확률로 분노 필살기 입력을 낸다

## Functional Requirements (mandatory)

- FR-1: MUST 컴퓨터 상대는 사람과 같은 입력(방향 넷과 버튼 넷, 0 또는 1)만 내고 엔진의 상태를 직접 바꾸지 않는다.
- FR-2: MUST 싸우는 단계가 아니면 입력을 비우고 이어서 낼 입력을 버린다.
- FR-3: MUST 전술은 위에서부터 처음 판단을 내리는 것이 이긴다: 방어 유지·반격, 행동 불가 시 가만히, 상대 공격에 대응, 대공 어퍼, 쉬는 중, 분노 필살기, 접근과 공격.
- FR-4: MUST 상대가 기술을 쓰기 시작하면 난이도별 반응 지연(아주 쉬움 16~22, 조금 쉬움 12~16, 보통 10~14, 어려움 6~10프레임)을 새로 정하고, 지연이 지난 뒤 판정이 끝나기 전까지 높이에 맞춰 막는다. 놓칠 확률은 난이도별이다.
- FR-5: MUST 상대 기술이 헛친 뒤 후딜이면 난이도별 확률로 약펀치로 반격하고, 발동이 6프레임 이상 남은 느린 기술은 난이도별 확률로 약펀치로 끊는다.
- FR-6: MUST 날아 드는 상대(높이 25 초과, 내려오는 중, 거리 120 안)는 쉬는 중이 아니면 난이도별 확률로 대공 어퍼 입력으로 받는다.
- FR-7: MUST 쉬는 중에는 가만히 있고, 상대가 150보다 멀면 다가온다. 쉬는 시간은 행동마다 정해지고 난이도 배율이 곱해진다.
- FR-8: MUST 분노 게이지가 가득이고 거리 110 안이면 프레임마다 5퍼센트 확률로 분노 필살기 입력을 낸다.
- FR-9: MUST 거리 230을 넘으면 걸어서 다가가고 가끔 앞 두 번으로 달려 붙으며, 94~230이면 걸어서 다가가고, 거리 190 안이면 가끔 낮은 점프를 한다.
- FR-10: MUST 거리 94 안에서는 난이도별 공격 빈도로 공격 하나를 고르고, 막고 있는 상대는 난이도별 확률로 읽은 방어 자세에 맞춰 압박한다.
- FR-11: MUST 난이도는 라운드와 전적으로 정한다: 1라운드 아주 쉬움, 2라운드 조금 쉬움, 3라운드부터 보통이고, 플레이어가 지고 있으면 한 단계 낮춘다. 어려움은 옵션으로만 고를 수 있고 이 규칙으로는 나오지 않는다.

## Constraints (mandatory)

- CON-1: MUST 난이도를 플레이어가 고르지 않는다.
- CON-2: MUST 컴퓨터 상대는 엔진의 읽기 전용 상태만 쓴다.
- CON-3: MUST 같은 무작위 값이면 같은 판단이 나온다.

## Success Criteria (mandatory)

- SC-1: 1라운드는 아주 쉬움이고 라운드가 오를수록 단계가 오르며 지고 있으면 한 단계 낮다.
- SC-2: 난이도가 높을수록 반응이 빠르고 덜 놓친다.
- SC-3: 같은 시드에서 컴퓨터끼리 한 판의 결과(프레임 수, 승자, 모든 프레임의 요약)가 언제나 같다.
- SC-4: 컴퓨터 상대의 모든 전술이 테스트로 확인된다.
