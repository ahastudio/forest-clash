# 컴퓨터 상대

## Background

혼자 하는 대전에는 사람처럼 싸우는 컴퓨터 상대가 필요하다.
처음 하는 사람이 바로 지지 않도록 처음에는 봐주고, 라운드가 갈수록 어려워져야 한다.
컴퓨터 상대는 사람과 같은 입력(방향 넷과 버튼 넷)만 내고 엔진의 상태를 직접 바꾸지 않는다.

## Goal

엔진의 상태를 보고 막고, 반격하고, 접근하고, 공격을 고르는 컴퓨터 상대를 만든다.
난이도는 선택하지 않고 라운드와 전적으로 정해져, 처음에는 봐주면서 시작해 점점 어려워진다.

## How it works

### 입력

- 컴퓨터 상대는 방향 넷과 버튼 넷을 0 또는 1로 낸다. 사람의 키 입력과 같은 모양이라 엔진은 둘을 구별하지 않는다.
- 싸우는 단계가 아니면 입력을 비우고 이어서 낼 입력(연속 입력)도 버린다.

### 판단

- 위에서부터 처음 판단을 내리는 전술이 이긴다: 막는 중 방어 유지·반격 → 행동할 수 없으면 가만히 → 상대 공격에 대응 → 대공 어퍼 → 쉬는 중 → 분노 필살기 → 접근과 공격.
- 상대 기술이 발동하는 것을 본 뒤 반응 지연(난이도별 6~22프레임)을 두고 높이에 맞춰 막는다. 하단은 앉아서 막는다. 쉬울수록 자주 놓친다.
- 헛친 기술의 후딜에는 약펀치로 반격하고, 발동이 느린 기술은 약펀치로 끊는다. 날아 드는 상대는 대공 어퍼로 받는다.
- 중심 거리 94 안까지 붙은 뒤 공격한다. 멀면 걸어서 다가가고 아주 멀면 가끔 앞 두 번으로 달려 붙으며, 거리 190 안에서는 가끔 낮은 점프로 파고든다.
- 막고 있는 상대는 방어 자세를 읽어(서서 막으면 하단과 잡기, 앉아서 막으면 상단과 잡기) 압박한다(아주 쉬움은 하지 않고 난이도가 높을수록 자주 한다).

### 난이도

- 난이도는 아주 쉬움, 조금 쉬움, 보통, 어려움 네 단계다. 단계마다 반응 지연, 놓칠 확률, 반격·끊기 확률, 공격 빈도, 행동 간격, 압박 확률, 대공 확률이 다르다.
- 1라운드는 아주 쉬움, 2라운드는 조금 쉬움, 3라운드부터는 보통이다. 플레이어가 지고 있으면(컴퓨터가 더 많이 이겼으면) 한 단계 낮춘다. 어려움은 옵션으로만 고를 수 있고 이 규칙으로는 나오지 않는다.
