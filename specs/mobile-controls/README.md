# 모바일 조작

## Background

숲속대전은 키보드로 조작하도록 만들어졌다.
폰에는 키보드가 없어 게임을 할 수 없으므로 화면에 조이스틱과 버튼을 놓는다.
조이스틱은 모바일 같은 터치 기기에서만 보여야 하고, 모바일은 언제나 1P로 조작한다.

## Goal

폰에서 걷기, 점프, 앉기, 공격 버튼 네 개로 컴퓨터와 대전할 수 있게 한다.
키보드로 하는 PC 화면에는 조이스틱이 나타나지 않게 한다.

## How it works

### 화면 배치

- 왼쪽 아래에 조이스틱, 오른쪽 아래에 공격 버튼 네 개, 오른쪽 위에 일시정지 버튼이 있다.
- 버튼은 위 줄이 약펀치와 강펀치, 아래 줄이 약킥과 강킥이다. 키보드 배치와 같다.
- 이 요소는 터치 기기에서만 보인다. 터치가 아닌 기기에서는 숨겨져 있다.

### 조이스틱

- 손가락이 처음 닿은 곳이 가운데다. 조이스틱 어디에 닿아도 그곳에서 움직인 만큼이 기울기가 된다.
- 조이스틱 너비의 0.4배만큼 밀면 끝까지 민 것이다. 더 밀면 기준점이 손가락 쪽으로 따라와서 반대로 밀 때 바로 반응한다.
- 기울기가 끝까지의 0.35배보다 작으면 아무 방향도 누르지 않은 것으로 본다.
- 방향은 여덟 방향으로 나뉜다. 곧게 위로 밀면 위만 눌려 제자리 점프가 나가고, 비스듬히 밀어야 위와 앞(또는 뒤)이 함께 눌린다.
- 손가락을 떼면 모든 방향을 놓고 손잡이가 가운데로 돌아온다.

### 입력 전달

- 조이스틱과 버튼은 1P의 키보드 입력(방향키, I K O L)을 눌렀다 놓는 것과 같은 일을 한다. 엔진, 컴퓨터 상대, 입력 기록은 바뀌지 않는다.
- 일시정지 버튼은 Space와 같다. 모바일에는 Space가 없으므로 일시정지를 풀 방법이 필요하다.

### 안내 문구

- 입력 장치는 시작할 때 `pointer: coarse` 여부로 정한다(`touch` 또는 `keyboard`).
- 타이틀 화면 아래 문구와 일시정지 화면은 입력 장치에 맞게 바뀐다. 터치 기기에서는 Space 대신 일시정지 버튼(⏸)을 안내하고 키보드 그림은 그리지 않는다.
- 문구는 입력 장치별 표(`GUIDES`)에 있어서 새 입력 장치는 표에 한 줄을 더하면 된다.

### 브라우저 동작 막기

- 두 손가락으로 함께 조작하면 브라우저가 화면을 확대하려 한다. 확대 동작(`gesturestart`)과 조작 영역의 터치 기본 동작, 길게 눌러 뜨는 메뉴를 막는다.
