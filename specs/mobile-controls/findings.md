## Requirements

- 화면에 조이스틱과 버튼을 놓고 모바일은 언제나 1P로 조작한다.
- 조이스틱과 버튼은 터치 기기에서만 보인다.
- 모바일은 1P로만 조작하며 온라인 대전은 이 기능의 범위가 아니다.

## Research Findings

### 코드베이스 구조

- `src/input/keyboard.ts`: 눌린 키를 기억하고 플레이어별 입력으로 바꾼다. 모바일은 이 입력의 1P 키를 대신 누르고 뗀다.
- `src/engine/locomotion.ts`: 위 입력이 켜진 프레임에 점프를 시작하고, 그 순간의 왼쪽·오른쪽 입력으로 점프 방향을 정한다(`tryJump`, `stickDirection`).

### 기존 패턴

- 화면 코드는 엔진의 상태를 읽기만 한다. 안내 문구도 같은 방식으로 `View`에 담아 읽는다.
- 갈래가 많으면 조건문을 늘어놓지 않고 표(객체)로 고른다. 입력 장치별 안내 문구도 표(`GUIDES`)로 둔다.

## Technical Decisions

| Decision | Rationale |
| -------- | --------- |
| 조이스틱과 버튼을 1P 키보드 입력으로 옮긴다 | 엔진, 컴퓨터 상대, 입력 기록을 바꾸지 않고 같은 규칙을 쓰기 위해 |
| 터치 기기에서만 보이는 것은 CSS의 `pointer: coarse`로 정한다 | 자바스크립트 분기 없이 터치가 아닌 기기에서 숨기기 위해 |
| 일시정지 버튼을 넣는다 | 모바일에는 Space가 없어서 알림 등으로 멈춘 게임을 이어 갈 방법이 필요하기 때문에 |
| 조이스틱은 처음 닿은 곳을 가운데로 삼는다 | 고정된 가운데를 기준으로 하면 손가락이 가운데에서 벗어나 닿을 때 의도하지 않은 방향이 눌리기 때문에 |
| 방향을 여덟 방향으로 나눈다 | 곧게 위로 밀었는데 옆 방향이 섞여 점프 방향이 틀어지는 것을 막기 위해 |
| 끝까지 민 거리를 넘으면 기준점이 손가락을 따라온다 | 반대로 밀 때 바로 반응해 앞뒤 전환이 빨라지게 하기 위해 |
| 확대 동작과 조작 영역의 터치 기본 동작을 막는다 | 두 손가락 조작이 확대로 읽히는 것을 막기 위해 |
| 안내 문구를 입력 장치별 표(`GUIDES`)에 둔다 | 화면 코드에 장치 분기를 흩뿌리지 않고, 새 입력 장치는 표에 한 줄만 더하면 되게 하기 위해 |
| 입력 장치는 시작할 때 `pointer: coarse`로 한 번 정한다 | CSS가 조이스틱을 보이게 하는 조건과 같은 기준을 쓰기 위해 |
| 일시정지 토글을 `Game.togglePause`로 모은다 | Space와 일시정지 버튼이 같은 동작을 따로 적지 않게 하기 위해 |

## Issues Encountered

### 1. 두 손가락으로 조작하면 화면이 확대된다

**문제**:

한 손은 조이스틱, 다른 손은 버튼을 누르면 화면이 갑자기 확대된다.

**원인**:

두 손가락이 닿으면 브라우저가 확대 동작으로 읽는다.

**해결**:

확대 동작(`gesturestart`)과 조작 영역의 터치 시작·이동·길게 누르기 기본 동작을 막고, 뷰포트에서 확대를 껐다.

**결과**:

실제 폰에서 두 손가락으로 조작해도 확대되지 않는다.

### 2. 점프가 잘 나가지 않는다

**문제**:

조이스틱을 위로 밀어도 점프가 잘 나가지 않거나 방향이 틀어진다.

**원인**:

조이스틱을 고정된 가운데 기준으로 읽어서, 손가락이 가운데에서 벗어나 닿으면 의도하지 않은 방향이 눌린다. 위로 밀 때 옆 방향이 섞이면 점프 방향이 틀어진다.

**해결**:

처음 닿은 곳을 가운데로 삼고, 여덟 방향으로 나누고, 끝까지 민 거리를 넘으면 기준점이 따라오게 했다.

**결과**:

곧게 위로 밀면 위만 눌려 제자리 점프가 나가고, 비스듬히 밀면 앞(뒤) 점프가 나간다. 실제 폰에서 점프가 잘 나간다.

### 3. 터치 기기의 안내 문구에 Space와 키보드 그림이 나온다

**문제**:

타이틀과 일시정지 화면이 Space와 키보드 배치를 안내한다. 폰에는 해당하는 키가 없다.

**원인**:

안내 문구가 키보드 기준으로 한 가지뿐이다.

**해결**:

입력 장치별 안내 표(`GUIDES`)를 두고, 터치 기기에서는 일시정지 버튼을 안내하며 키보드 그림을 그리지 않는다.

**결과**:

터치 기기의 타이틀과 일시정지 화면에 Space 안내가 나오지 않는다.

## Learnings

### 터치 조작은 처음 닿은 곳을 기준으로 읽는다 (2026-10-20)

화면에 놓인 조이스틱은 손가락이 닿는 위치가 매번 다르다.
고정된 가운데 기준으로 읽으면 의도하지 않은 방향이 눌리므로, 처음 닿은 곳을 가운데로 삼고 움직인 만큼만 읽는다.

### 입력 장치마다 다른 것은 표에 모은다 (2026-10-20)

안내 문구처럼 입력 장치마다 달라지는 것은 화면 코드에 분기를 넣지 않고 표 하나에 모은다.
새 입력 장치는 표에 한 줄을 더하면 된다.
