# 이동

## Background

대전 격투 게임에서 이동은 공격과 방어의 바탕이다.
거리를 좁히고 벌리는 속도, 공중에 머무는 시간, 대시의 빈틈이 싸움의 흐름을 정한다.
이 게임은 걷기, 앉기, 점프, 달리기, 뒤 대시, 구르기와 두 캐릭터가 서는 무대(벽, 간격)를 하나의 이동 규칙으로 묶는다.

## Goal

걷기, 앉기, 점프(일반과 낮은 점프), 달리기, 뒤 대시, 구르기를 프레임 단위 수치로 정하고, 벽과 최대 간격 안에서 두 캐릭터가 겹치지 않고 마주 보게 한다.

## How it works

### 땅에서의 이동

- 걷기는 앞으로 프레임당 2.4, 뒤로 1.9다. 아래를 누르면 앉고 피격 높이가 54(서 있을 때 96)가 된다.
- 앞 두 번을 누른 뒤 앞을 누르고 있으면 프레임당 5.0으로 달린다. 앞을 놓으면 8프레임 동안 멈춘다.
- 땅에 서 있는 동안 캐릭터는 상대를 바라본다.

### 점프

- 위를 누르면 4프레임 도약 준비 뒤에 뛴다.
- 도약하는 순간 위를 누르고 있으면 일반 점프(상승 속도 13, 체공 약 46프레임, 가로 3.0), 이미 놓았으면 낮은 점프(상승 속도 9.6, 체공 약 34프레임, 가로 3.6)다.
- 가로 속도는 도약 순간에 정해지고 공중에서는 바꿀 수 없다. 위를 먼저 누른 뒤 앞을 눌러도 앞으로 뛴다.
- 땅에 닿으면 3프레임 동안 움직일 수 없다.

### 대시와 구르기

- 뒤 두 번은 26프레임의 뒤 대시다(속도 5.2, 14프레임부터 0.8배씩 줄어든다). 시작 3프레임 뒤부터 16프레임까지는 아래쪽이 비어 하단 공격을 넘는다.
- 약펀치+약킥은 구르기다. 30프레임이고 앞 9프레임은 무적이며, 앞 20프레임 동안 프레임당 4.4로 움직인다. 뒤를 누르고 있으면 뒤로 구른다.

### 무대

- 캐릭터는 벽(가로 300~900) 안에 있다.
- 두 캐릭터는 최대 440 이상 떨어지지 않는다. 벗어나는 쪽(더 빠르게 멀어지는 쪽)이 끌려온다.
- 둘 다 땅에 있고 쓰러지거나 잡히지 않았으면 몸이 겹치지 않게 밀어낸다(반폭 26). 벽에 붙은 쪽은 움직이지 않고 상대가 겹친 만큼 밀려난다.
